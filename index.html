Why I'm here

My goals in
web development class

Every project on this site is a step toward the same target: shipping real websites that people actually use.

  • Learn every layer of the craft — from semantic markup and layout to interaction, so I can build a website end to end for anyone who needs one.
  • Get genuinely good at the core three — HTML, CSS and JavaScript before reaching for frameworks.
  • Turn the skill into work — take on paid client projects and internships while I'm still studying.
  • Design as well as build — pair the code with interfaces that look considered, not accidental.
